# NEXUS — v1.1.0

A minimal responsive launch hub with direct links to PANEL, PULSE, SHIFTLY, SAUCE and RELIC. No backend, embedded apps, shared storage or build step.

[Launch hub](https://theparsifal21.github.io/Nexus/)

## Deployment
Enable GitHub Pages from `main`, `/ (root)`. Live deployment and destination availability have not been verified.

## Installation
Open the HTTPS hub in Chrome on Android and choose Install app or Add to Home screen when available. On iOS use Safari Share → Add to Home Screen. The hub shell supports offline caching; linked applications manage their own connectivity. Installation has not been tested on a real device.

## v1.2.0
Added Android-compatible 192px and 512px PNG icons, a dedicated install button and refreshed offline cache. Open in Chrome and select Install NEXUS; browser installation eligibility applies.
